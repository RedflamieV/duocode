# DuoCode

Приложение для совместной работы **Claude Code** и **Codex** в одном чате.
Не терминалы, а полноценный интерфейс: сообщения, шаги агентов, диффы, подтверждения и лимиты.

## Возможности

- **Общий чат на двоих.** Сообщение адресуется Claude, Codex или обоим сразу
  (переключатель под полем ввода или `@claude` / `@codex` в начале сообщения).
- **Общий контекст.** Перед каждым ходом агент получает сводку того, что в чате произошло
  без него: что вы писали другому агенту и что тот ответил.
- **Агенты вызывают друг друга.** У Claude есть инструмент `ask_codex`, у Codex — `ask_claude`.
  Агент сам решает подключить напарника (или делает это по вашей просьбе). Работа
  подключённого агента видна прямо внутри карточки, а его ответ возвращается вызвавшему.
  Обратный вызов внутри такого запроса заблокирован, чтобы агенты не ждали друг друга вечно.
- **«Попросить проверить».** Под каждым ответом есть кнопка, которая отправляет его на
  ревью другому агенту.
- **Подтверждения в чате.** Команды и правки обоих агентов можно разрешить один раз, разрешать
  всегда или отклонить. Режимы: «Спрашивать», «Авто-правки», «Полный доступ».
- **Вопросы агентов.** Если Claude или Codex задаёт вопрос с вариантами, он появляется в чате
  карточкой с кнопками и полем для своего ответа.
- **Вложения.** Картинки и файлы: кнопка-скрепка, вставка скриншота через Ctrl+V или
  перетаскивание в поле ввода.
- **Сначала план.** Кнопка «План» у поля ввода: агент ничего не меняет, а предлагает план.
  Его можно выполнить или отправить на доработку.
- **Дописать по ходу работы.** Сообщение работающему агенту не ждёт очереди, а попадает
  прямо в его текущую работу.
- **Команды «/».** `/compact` (сжать контекст), `/clear` (начать заново), `/review` (код-ревью),
  `/init` (файл с инструкциями для агента), а также свои команды и навыки Claude Code и
  промпты Codex из `~/.codex/prompts`. Меню команд появляется, когда вы набираете «/».
- **Заполненность контекста** каждого агента видна в шапке чата. Там же кнопки «Сжать»
  и «Начать заново».
- **Вызов напарника из одиночного режима.** Пишете только Codex — он сам подключит Claude,
  если это реально поможет, и продолжит один. В меню чата можно выбрать: «Сам решает»,
  «Спрашивать меня» или «Запрещено».
- **Проекты из нескольких папок.** Проект — это название и одна или несколько папок (например,
  фронтенд и бэкенд в разных местах). Чаты живут внутри проектов; агенты работают в основной
  папке и видят остальные (Claude — `--add-dir`, Codex — разрешённые для записи папки песочницы).
  Откат, @файлы и панель Git охватывают все папки.
- **Свой порядок проектов.** Перетаскивайте заголовки групп в боковой панели или используйте
  кнопки «выше/ниже», которые появляются при наведении и фокусе. Порядок, включая «Чаты без
  проекта», сохраняется после перезапуска и больше не меняется от активности чатов.
- **Проекты из GitHub.** Кнопка «Проект из GitHub» в боковой панели или Настройки → GitHub:
  подключение через установленный [GitHub CLI](https://cli.github.com/) (`gh`), выбор доступного
  репозитория (включая приватные), клонирование в выбранную папку и добавление в проекты.
  Вход проходит в браузере и консоли `gh auth login`; учётные данные хранит gh. Нужен Git.
- **Откат правок.** Перед каждым ответом DuoCode делает снимок проекта (в отдельном скрытом
  репозитории, ваш git не трогается). Под ответом видно, какие файлы агент изменил, и есть
  кнопки «Откатить» и «Вернуть».
- **Панель «Изменения»**: файлы с незакоммиченными правками, дифф, откат файла, коммит
  с сообщением от агента, push.
- **«Раздельно» в режиме «Оба»**: каждый агент решает задачу в своей копии проекта
  (git worktree), потом вы сравниваете и применяете лучший вариант.
- **«Авто»**: задачу берёт агент, у которого больше свободного лимита.
- **Прогноз лимитов** («кончится ~чт 14:00») и уведомления: почти исчерпан, кончится раньше
  сброса, снова доступен.
- **Статистика**: токены по дням за 14 дней и расход по чатам.
- **@файлы**: наберите `@` в поле ввода — поиск по файлам проекта.
- **Сценарии**: цепочки шагов вроде «Claude планирует → Codex пишет → Claude проверяет»,
  встроенные и свои.
- **Telegram**: уведомления, подтверждения и ответы на вопросы с телефона, ответ на
  сообщение бота уходит в чат. Токен бота — в настройках.
- **Управление прямо в чате с ботом** — без туннелей: `/chats`, `/new`, `/to`, `/plan`, `/stop`,
  `/limits`; задачи — обычными сообщениями (можно со скриншотом), ход работы — в одном
  обновляющемся сообщении.
- **Мини-приложение в Telegram**: полноценное управление DuoCode с телефона — чаты, задачи
  агентам, подтверждения, вопросы, планы, откат, лимиты. Связь через туннель на выбор:
  Cloudflare (DuoCode скачивает `cloudflared` сам), localhost.run (встроенный ssh) или свой адрес, каждый запрос проверяется по подписи Telegram
  (initData) и ID владельца.
- **Файлы компьютера в Telegram.** Кнопка «Файлы» в чате открывает папки проекта: текст и код
  можно читать прямо на телефоне, изображения просматривать, остальные форматы скачивать.
  Ссылки агентов на файлы и файловые вложения тоже открывают просмотр. Большие текстовые
  файлы показываются частично; полная версия доступна для скачивания. Доступ ограничен
  открытыми проектами, папками чатов и вложениями; компьютер с DuoCode должен быть включён.
- **Поиск по всем сообщениям** и экспорт чата в Markdown.
- **Трей и горячая клавиша** Ctrl+Shift+Space.
- **Общая память проекта** `.duocode/memory.md`: её видят оба агента, и оба могут её
  дополнять сами (инструмент `remember`).
- **Внешний вид**: семь стандартных тем и восемь аниме-тем с локальными иллюстрациями,
  своими палитрами и атмосферными эффектами. Выбор — в «Настройки → Внешний вид»;
  анимации можно смягчить или отключить. Также: размер текста, ширина чата, плотность,
  шрифт кода, свёрнутые шаги, клавиша отправки.
- **Наглядные шаги**: команды с выводом, правки с диффом, план, поиск, размышления.
- **Лимиты обоих** в боковой панели. Claude: сессия (5ч), неделя и лимиты по моделям,
  обновляются вживую во время работы. Codex: окно 5ч и неделя, тоже вживую. Плюс расход
  токенов за сегодня.
- **Продолжение старых сессий** из терминала: на экране нового чата.
- Тихое автообновление из релизов GitHub.
- Выбор модели и уровня размышлений для каждого агента, уведомления, когда агент закончил или ждёт подтверждения,
  светлая и тёмная тема.

## Как это устроено

DuoCode запускает **ваши** установленные `claude` и `codex` и пользуется их входом и подписками:

- Claude Code — `claude -p --output-format stream-json`, по процессу на ход, сессия
  продолжается через `--resume`;
- Codex — постоянный `codex app-server` (JSON-RPC), один тред на чат;
- `bridge/mcp.js` — маленький MCP-сервер, который оба агента подключают как инструмент `duo`.
  Он передаёт вызовы `ask_codex`, `ask_claude` и запросы подтверждений Claude в приложение
  через локальный порт со случайным токеном.

Чаты хранятся в папке данных приложения (`%APPDATA%\DuoCode\rooms` на Windows).

## Требования

- Claude Code: `irm https://claude.ai/install.ps1 | iex` (Windows) или
  `curl -fsSL https://claude.ai/install.sh | bash`, затем `claude` → вход.
- Codex: `npm i -g @openai/codex` или архив с GitHub, затем `codex` → вход через ChatGPT.

## Разработка

```bash
npm install
npm test          # проверки проектов, файлов Telegram и GitHub
npm start          # сборка интерфейса и запуск
npm run dist:win   # установщик для Windows → dist/
```

## Структура

```
main.js                окно, IPC, лимиты, HTTP-мост
preload.js             API для интерфейса
src/rooms.js           чаты: контекст, делегирование, подтверждения, очередь
src/agents/claude.js   ход Claude Code (stream-json → части сообщения)
src/agents/codex.js    клиент codex app-server
bridge/mcp.js          MCP-сервер «duo» для обоих агентов
src/claudeLimits.js    лимиты Claude
src/codexLimits.js     лимиты Codex
src/history.js         старые сессии и статистика из локальных логов
renderer/src/          интерфейс (Preact)
```

## Выпуск новой версии

1. Поднять `version` в `package.json` и запушить в `main`.
2. GitHub Actions соберёт установщик и опубликует релиз `v<версия>`, а установленные копии
   DuoCode скачают обновление сами и предложат перезапуститься.
