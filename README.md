# DuoCode

Приложение для совместной работы **Claude Code** и **Codex** в одном чате.
Не терминалы, а полноценный интерфейс: сообщения, шаги агентов, диффы, подтверждения и лимиты.

## Возможности

- **Общий чат на двоих.** Сообщение адресуется Claude, Codex или обоим сразу
  (переключатель под полем ввода или `@claude` / `@codex` в начале сообщения).
- **Общий контекст.** Перед каждым ходом агент получает сводку того, что в чате произошло
  без него: что вы писали другому агенту и что тот ответил.
- **Агенты вызывают друг друга.** У Claude есть инструмент `ask_codex`, у Codex — `ask_claude`.
  Агент сам решает подключить напарника (или делает это по вашей просьбе). Работа
  подключённого агента видна прямо внутри карточки, а его ответ возвращается вызвавшему.
  Обратный вызов внутри такого запроса заблокирован, чтобы агенты не ждали друг друга вечно.
- **«Попросить проверить».** Под каждым ответом есть кнопка, которая отправляет его на
  ревью другому агенту.
- **Подтверждения в чате.** Команды и правки обоих агентов можно разрешить один раз, разрешать
  всегда или отклонить. Режимы: «Спрашивать», «Авто-правки», «Полный доступ».
- **Наглядные шаги**: команды с выводом, правки с диффом, план, поиск, размышления.
- **Лимиты обоих** в боковой панели. Claude: сессия (5ч), неделя и лимиты по моделям,
  обновляются вживую во время работы. Codex: окно 5ч и неделя, тоже вживую. Плюс расход
  токенов за сегодня.
- **Продолжение старых сессий** из терминала: на экране нового чата.
- Выбор модели для каждого агента, уведомления, когда агент закончил или ждёт подтверждения,
  светлая и тёмная тема.

## Как это устроено

DuoCode запускает **ваши** установленные `claude` и `codex` и пользуется их входом и подписками:

- Claude Code — `claude -p --output-format stream-json`, по процессу на ход, сессия
  продолжается через `--resume`;
- Codex — постоянный `codex app-server` (JSON-RPC), один тред на чат;
- `bridge/mcp.js` — маленький MCP-сервер, который оба агента подключают как инструмент `duo`.
  Он передаёт вызовы `ask_codex`, `ask_claude` и запросы подтверждений Claude в приложение
  через локальный порт со случайным токеном.

Чаты хранятся в папке данных приложения (`%APPDATA%\DuoCode\rooms` на Windows).

## Требования

- Claude Code: `irm https://claude.ai/install.ps1 | iex` (Windows) или
  `curl -fsSL https://claude.ai/install.sh | bash`, затем `claude` → вход.
- Codex: `npm i -g @openai/codex` или архив с GitHub, затем `codex` → вход через ChatGPT.

## Разработка

```bash
npm install
npm start          # сборка интерфейса и запуск
npm run dist:win   # установщик для Windows → dist/
```

## Структура

```
main.js                окно, IPC, лимиты, HTTP-мост
preload.js             API для интерфейса
src/rooms.js           чаты: контекст, делегирование, подтверждения, очередь
src/agents/claude.js   ход Claude Code (stream-json → части сообщения)
src/agents/codex.js    клиент codex app-server
bridge/mcp.js          MCP-сервер «duo» для обоих агентов
src/claudeLimits.js    лимиты Claude
src/codexLimits.js     лимиты Codex
src/history.js         старые сессии и статистика из локальных логов
renderer/src/          интерфейс (Preact)
```
