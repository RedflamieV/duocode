# Другие модели через Claude Code

Пользователь поручил реализацию после выбора подключения GLM через установленный Claude Code. Его команды, MCP-мост к Codex, подтверждения и интерфейс шагов остаются движком агента. Добавляются несколько именованных профилей совместимого Anthropic Messages API: адрес, ключ, способ авторизации, модели и модель по умолчанию. Есть шаблон Z.ai и произвольный профиль. OpenAI Chat Completions требует другого движка и в эту реализацию не входит.

В настройках «Агенты» пользователь создаёт и редактирует профили; в новом и существующем чате выбирает профиль и модель, задаёт значение по умолчанию для новых чатов. Пустой идентификатор профиля означает прежний Claude. Профили не изменяют глобальную конфигурацию установленного Claude Code.

Ключи остаются в главном процессе, шифруются safeStorage при сохранении; если шифрование недоступно, действуют до закрытия приложения, о чём сообщает форма. Интерфейс получает только признак наличия ключа. Настройки запуска переопределяют конфликтующую авторизацию и модели для процесса Claude Code; временный файл имеет права 0600, удаляется после хода и при следующем старте после аварии. Ключи не помещаются в аргументы процесса, сообщения, MCP-конфиг или экспорт чата.

Смена профиля или адреса начинает новую сессию Claude Code с пересказом видимой истории. Переключение во время работы запрещено. Неизвестный профиль и отсутствующий ключ дают ошибку, без отката на Anthropic. Пользовательские модели не получают --effort, если поддержка явно не включена. Внутренние псевдонимы Opus/Sonnet/Haiku и фоновая модель направляются в выбранную модель провайдера. Лимиты и бюджет подписки Claude не относятся к другим профилям; метаданные ответа сохраняют фактический профиль и модель.

## Approaches

Рассмотрены профили совместимого API поверх Claude Code и самостоятельный агент поверх OpenAI-совместимого API. Выбран первый после обсуждения верификации Claude: он сохраняет инструменты существующего агента и использует отдельный ключ провайдера. Совместимость конкретной модели с tool calling и Claude Code зависит от провайдера; реальное подключение проверяется пользователем со своим ключом.

## Проверка

Node-тесты проверяют валидацию, хранение и редактирование ключей, изоляцию авторизации, параметры реального запуска подменного CLI, сессии и бюджет. Сборка обоих интерфейсов обязательна; форма и переключатель проверяются в браузере с локальным тестовым API. Без ключа GLM нельзя подтвердить реальный ответ сервиса.
